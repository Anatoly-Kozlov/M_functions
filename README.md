# Библиотека функций M (Power Query)
Репозиторий содержит сборник полезных пользовательских функций на языке M для Power Query, призванный упростить и автоматизировать процесс обработки данных.


## Возможности

Библиотека включает функции для:

- **Очистки и трансформации данных**: Удаление пустых столбцов, трасформация столбцов


| Функция | Категория | Описание |
| :--- | :--- | :--- |
| `fxTableRemoveNullColumns` | Трансформация | Удаляет пустые колонки |
| `fxTableTransformColumn` | Трансформация | Трасформирует колонку с возможностью обращения к другим столбцам |

## Установка и использование

### Способ 1: Копирование функции (для разового использования)

1.  Перейдите в файл с нужной функцией, например, [`/functions/Text_Functions.m`](/functions/Text_Functions.m).
2.  Скопируйте код функции (блок `let...in`).
3.  В редакторе Power Query (Power BI/Excel) создайте новый пустой запрос, перейдите в **"Вид" -> "Расширенный редактор"**.
4.  Вставьте скопированный код, дайте запросу понятное имя (например, `FnCleanText`) и нажмите **"Готово"**.
5.  Теперь вы можете вызывать эту функцию в других запросах.
