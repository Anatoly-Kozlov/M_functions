# Библиотека функций M (Power Query)
Репозиторий содержит сборник полезных пользовательских функций на языке M для Power Query, призванный упростить и автоматизировать процесс обработки данных.


## Возможности

Библиотека включает функции для:

- **Очистки и трансформации данных**: Удаление пустых столбцов, трасформация столбцов


| Функция | Категория | Описание |
| :--- | :--- | :--- |
| `fxTableRemoveNullColumns` | Трансформация | Удаляет пустые колонки |
| `fxTableTransformColumn` | Трансформация | Функция трансформации столбца с возможностью обращения к данным из других столбцов |

## Установка и использование

1.  Импортируйте библиотеку с функциями в файл. Создайте пустой запрос к примеру с именем "my_pack" и введите формулу
`= Expression.Evaluate(Text.FromBinary(Web.Contents("https://raw.githubusercontent.com/Anatoly-Kozlov/M_functions/main/My_pack")),#shared)`
2. Обращение к фунциями происходит по формуле в виде `my_pack[имя_функции]()`
